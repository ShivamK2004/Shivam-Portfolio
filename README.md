# Shivam Kumar — Portfolio

Static site: open `index.html` in a browser. No build step.

- Edit projects in the `P` array at the top of `script.js`.
- Colors and fonts are the variables at the top of `style.css`.
- Deploy free: push this folder to a GitHub repo and enable GitHub Pages (or drag it into Netlify/Vercel).
- Add screenshots later: put images in an `img/` folder and add them to the project cards.
