## Built with

HTML, CSS and vanilla JavaScript. No framework and no build step.

## Project structure

```
├── index.html   # page structure and sections
├── style.css    # design, colours and layout
├── script.js    # project data, skills and filters
└── README.md
```

## Run locally

Open `index.html` in any browser. To serve it on a local address instead:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Edit the content

- **Projects:** edit the `P` list at the top of `script.js`.
- **Skills:** edit the `S` list at the bottom of `script.js`.
- **Colours and fonts:** edit the variables at the top of `style.css`.
- **Text sections:** edit `index.html`.

## Deploy

Push the folder to a GitHub repo, then open **Settings → Pages**, choose branch `main` and folder `/ (root)`, and save.
